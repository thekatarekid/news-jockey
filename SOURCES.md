# Starting sources

50 starting sources, ten per category. This is a practical selection for a US-focused collector, not an objective ranking or a claim that every entry is US-only. Official publisher RSS/Atom feeds were fetched and parsed successfully on **2 October 2026** from this Mac. Availability and feed freshness can change. Feed access is separate from rights to republish content.

The portal uses publisher-supplied feed text and links. No article-page scraping or paid API is needed for these starting feeds.
